# Nova

A Duolingo-style, level-based study app for primary students in India. Students take a placement test when they register and are assigned a starting level. Levels are short story scenes with questions in Marathi or English. Content is generated by an LLM from a fixed catalogue of characters, backdrops and props, validated, and cached so the app keeps working on weak internet.

Status: early development. Grades 1–4 are being built first to prove the architecture, with a design that extends to grade 7. The Dart package is still named `majhe_gaon` internally.

## Running the app
Requires the Flutter SDK matching `environment.sdk` in `pubspec.yaml`.

```
flutter pub get
flutter run --dart-define=GEMINI_API_KEY=your_key --dart-define=GROQ_API_KEY=your_key
```

The keys are optional. Without them the online LLM calls fail and the app should fall back to its local offline level generator (not yet verified end to end). Never commit real keys. Passing keys this way is a temporary stopgap until LLM calls move to a backend.

The entry point is `lib/main.dart`. There is an older second entry point, `lib/nova_main/main.dart`, which is being merged into it and should not be used for new work.

## Known issues
- The Bluetooth duel is mostly simulated and is being rebuilt on Android Nearby Connections.
- The app contains two overlapping code trees (`lib/core` + `lib/features` and `lib/nova_main`).
- Levels 1–4 are hard-coded (per-level branches and per-level painter widgets). New levels must go through the data-driven pipeline instead.
- LLM output is not yet validated, and API keys are used on the client.
- Test coverage is minimal.

## Contributing
One small task per branch. Do not push to the main line directly. Run `flutter analyze` and `flutter test` before opening a pull request. Do not commit secrets. Changes to the level JSON contract need the owner's approval.
