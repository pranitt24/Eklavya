# Scene renderer (A1 + A3) : how to wire it in

Unzip this pack into the repo ROOT (paths are repo-relative). Nothing existing is overwritten except nothing: all files are new.

## 1. pubspec.yaml: register the assets (do NOT list `_unsorted` or `tools`)
```yaml
flutter:
  assets:
    - assets/nova/manifest.json
    - assets/nova/backgrounds/
    - assets/nova/characters/
    - assets/nova/animals/
    - assets/nova/props/
    - assets/nova/environment/
    - assets/nova/demo/
```
Keep your existing asset entries. Then `flutter pub get`.

## 2. Run the demo (standalone, does not touch the app shell)
```
flutter run -t lib/scene_demo_main.dart
```
Pick a level, switch Marathi / English. Console prints NARRATE / SFX / ANSWER lines (these are the hooks to wire).

## 3. Checks
```
flutter analyze
flutter test test/scene/scene_models_test.dart     # run from repo root; package name assumed `majhe_gaon`
python -m unittest backend.tests.test_validator    # 29 tests
```

## 4. What each file does (lib/features/scene/)
- `level_models.dart`  tolerant parser for level v2 JSON (never throws on bad data)
- `nova_assets.dart`   resolves ids to files; `expression` -> pose via manifest `pose_map`; safe fallbacks
- `motion_sprite.dart` enter / loop / one-shot motions as transforms + pose cross-fade
- `scene_stage.dart`   backdrop + props (counted, pop-in) + actors in left/center/right slots
- `question_panel.dart` voice_input (tap fallback), spot_item, fill_blanks, match_following
- `level_player.dart`  runs timeline, shows question, applies on_correct/on_wrong, 2 wrong tries then reveals answer

## 6. Single source of truth for art ids
`assets/nova/manifest.json` (client) and `backend/asset_manifest.json` (server) are the SAME file, generated by `tools/process_assets.py`.
New art: add to the raw folders, update the script lists, re-run, copy the manifest to both places. Never hand-edit ids in `backend/catalog.py`.
